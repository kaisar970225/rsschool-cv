## Примеры кода

### Сравнение двух массивов (JavaScript)
Скрипт проверяет, являются ли два массива идентичными по длине и элементам:
```javascript
const arr1 = [2,5,-3,-3,10];
const arr2 = [2,5,-3,-3,10];
let sr = '';
for(i = 0; i < arr1.length; i++){
    if(arr1[i] !== arr2[i] || arr1.length !== arr2.length){
        i = arr1.length;
        sr = false;
    }else{
        sr = true;
    };
}
console.log(sr);
```
